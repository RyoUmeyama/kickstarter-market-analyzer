# Kickstarter Market Analyzer

Kickstarter製品の日本市場参入提案メールを自動生成するシステムです。

## 🎯 主な機能

1. **管理表からの自動抽出**
   - 管理表のステータス（F列）でフィルタリング
   - 選択したステータスの行を自動でkickstarterシートにコピー
   - ステータスに応じたテンプレートを自動選択

2. **テンプレートベースのメール生成**
   - Google Sheetsでテンプレートを管理
   - ステータス→テンプレート対応を設定シートで管理
   - クライアント様が自由にテンプレートを追加可能

3. **OpenAI API統合（任意）**
   - テンプレートにプロンプト（A3セル）を設定すれば、OpenAI APIで専門的な市場分析レポートを生成
   - プロンプトがなければ、テンプレート本文をそのまま使用
   - 具体的なデータ、実URL、競合分析を含む詳細レポート

4. **日本市場の類似製品検索**
   - Seleniumによるブラウザ自動化でMakuakeから類似製品を自動検索
   - 製品カテゴリから適切な検索キーワードをAIが自動生成
   - 検索結果（製品名、資金調達額、URL）をレポートに自動挿入

5. **共通プロンプト管理**
   - 「設定」シートで全テンプレート共通のAI出力ルールを管理
   - Markdown記号の除去、自然な文体など品質ルールを一元管理

6. **自動翻訳対応**
   - Google SheetsのGOOGLETRANSLATE関数により英語→日本語を自動翻訳

7. **メールマージ対応**
   - Google SheetsをCSV出力してThunderbirdのメールマージで一括送信可能
   - HTML形式メール対応（改行を`<br>`に自動変換）

## 📊 システム構成

### 運用フロー

```
Octoparse（スクレイピング）
    ↓
管理表（データ管理・ステータス管理）
    ↓
GitHub Actions「管理表から抽出してメール生成」
    ↓
kickstarterシート（メール本文生成）
    ↓
CSV出力 → Thunderbirdメールマージ → 送信
```

### シート構成

| シート名 | 用途 |
|---------|------|
| 管理表 | Octoparseで取得したデータを管理。F列でステータス管理 |
| kickstarter | メール生成用。管理表から抽出したデータを処理 |
| 設定 | 共通プロンプト、ステータス→テンプレート対応表 |
| ①1回目送信文 | 新規向けテンプレート |
| ②無返信用2回目送信 | 無返信2回目用テンプレート |
| ➂無返信3回目 | 無返信3回目用テンプレート |
| ④自動返信用　2回目送信 | 自動返信があった場合用 |
| ⑤好返信用　詳細レポート送信 | 好意的な返信があった場合用 |

### 設定シート

| セル範囲 | 内容 |
|---------|------|
| A1:A2 | 共通プロンプト（AI出力ルール） |
| C1:D1 | 「ステータス→テンプレート対応表」タイトル |
| C2:D2 | ヘッダー（ステータス/テンプレート） |
| C3:D以降 | ステータスとテンプレートの対応 |

**ステータス→テンプレート対応表（C:D列）:**

| ステータス（C列） | テンプレート（D列） |
|------------------|-------------------|
| （空白） | ①1回目送信文 |
| ②無返信2回目　要送信 | ②無返信用2回目送信 |
| ➂無返信3回目　要送信 | ➂無返信3回目 |
| ④自動返信　要送信 | ④自動返信用　2回目送信 |
| ⑤好返信　要レポ送信 | ⑤好返信用　詳細レポート送信 |

### 管理表の列構成

| 列 | 内容 |
|----|------|
| A | 番号 |
| F | 状況（ステータス）- プルダウン選択 |
| Y | name（メーカー名） |
| Z | email（送信先メールアドレス） |
| AA | URL（Kickstarter URL） |

### kickstarterシート（メール生成用）

| 列 | 列名 | 説明 |
|----|------|------|
| A | NO | 番号 |
| B | product_url | Kickstarter URL |
| C | template | テンプレート名（自動選択） |
| D | name | メーカー名 |
| E | to_email | 送信先メールアドレス |
| F | jp_subject | 日本語件名（自動生成） |
| G | en_subject | 英語件名（自動生成） |
| H | jp_body | 日本語本文（自動生成） |
| I | en_body | 英語本文（自動生成） |
| J | jp_body_html | 日本語本文HTML版 |
| K | en_body_html | 英語本文HTML版 |

## 🚀 日常的な使い方

### 1. 管理表でステータスを設定

1. 管理表のF列（状況）でプルダウンからステータスを選択
2. 送信対象のステータス：
   - `②無返信2回目　要送信`
   - `➂無返信3回目　要送信`
   - `④自動返信　要送信`
   - `⑤好返信　要レポ送信`

### 2. GitHub Actionsで実行

1. GitHubリポジトリの「Actions」タブを開く
2. **「管理表から抽出してメール生成」** を選択
3. 「Run workflow」ボタンをクリック
4. **ステータスをドロップダウンから選択**：
   - （空白＝新規）
   - ②無返信2回目　要送信
   - ➂無返信3回目　要送信
   - ④自動返信　要送信
   - ⑤好返信　要レポ送信
5. 「Run workflow」をクリックして実行

### 3. 処理内容

1. 管理表から選択したステータスの行を抽出
2. kickstarterシートにコピー（テンプレート自動選択）
3. OpenAI APIでメール本文を生成
4. 結果をkickstarterシートに書き込み

### 4. 結果確認・メール送信

1. Google Sheetsでkickstarterシートを確認
2. **CSV出力**: ファイル → ダウンロード → カンマ区切り形式（.csv）
3. **Thunderbirdメールマージ**で送信:
   - 送信先: `{{to_email}}`
   - 件名: `{{jp_subject}}` または `{{en_subject}}`
   - 本文（HTML）: `{{jp_body_html}}` または `{{en_body_html}}`

## 🆕 テンプレート・ステータスの追加

### 新しいテンプレートを追加する場合

1. **新しいシートを作成**（例: `⑥新規顧客向け`）
2. **テンプレート構造**:
   ```
   A1: 英語件名
   B1: =GOOGLETRANSLATE(A1, "en", "ja")

   A2: 英語本文
   B2: =GOOGLETRANSLATE(A2, "en", "ja")

   A3: プロンプト（日本語、任意）
   ```
3. **設定シートのC:D列**に対応を追加:
   ```
   C列: ⑥新ステータス　要送信
   D列: ⑥新規顧客向け
   ```
4. **GitHub Actionsで選択肢を同期**:
   - GitHubの「Actions」タブを開く
   - **「ステータス選択肢を同期」** を実行
   - 設定シートの内容がワークフローの選択肢に自動反映される

### プレースホルダー

- `{{URL}}`: Kickstarter URLに置換
- `{{name}}`: メーカー名に置換
- `{{レポート}}`: OpenAI生成レポートに置換（A3プロンプトがある場合）

## ⚙️ 共通プロンプト管理

### 共通プロンプトの編集

全テンプレートに適用されるAI出力ルールを変更したい場合：

1. スプレッドシートの「設定」シートを開く
2. **A2セル**の内容を編集
3. 保存（自動保存）

**編集例:**
- Markdown記号の禁止ルール
- AI的な表現の禁止リスト
- 出力フォーマットの指定

### ステータス→テンプレート対応の編集

1. 「設定」シートのC:D列を編集
2. C列: ステータス値（管理表のF列と完全一致）
3. D列: 対応するテンプレートシート名

## 🎓 トラブルシューティング

### よくある問題

**抽出件数が0件**
- 管理表のF列のステータスが選択したものと完全一致しているか確認
- AA列にKickstarter URLが入力されているか確認

**テンプレートが見つからない**
- 設定シートのC:D列の対応表を確認
- テンプレートシート名が正確か確認

**OpenAI APIエラー**
- APIキーが正しく設定されているか確認
- クレジット残高を確認
