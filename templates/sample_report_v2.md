# ① 製品特徴・日本市場での通用度評価

**要点（スペック/訴求）**

* **超小型・軽量**：本体約2.5lbs（≒1.13kg）。フットプレート等と併用し全身トレ可能。([キックスターター][2])
* **最大100lb+の可変レジスタンス**。電源コード/電池不要を強調（＝自力式クラッチ）。アプリ依存なしを謳う一方、ブランドとしては**コーチングApp/BT接続のエコシステム**を保有（Air自体のBT搭載有無は資料により記述揺れ。後述）。([キックスターター][3])
* **資金調達実績（2025/6/24→7/24の31日）**：388人 / **$143,110（約2,176万円）**で成功。平均Pledge **$368.84（約56,100円）**。([Kicktraq][4])

**日本での通用性（新規性/革新性/訴求力）評価**

* **新規性：中** … 既に日本では**据置型〜可搬型の「ケーブル/バンド式ホームジム」**がMakuakeで複数成立（例：INNODIGYM等）。100lb級の可搬機は希少だが**完全な新カテゴリではない**。([Makuake(マクアケ)][5])
* **革新性：中** … 2.5lbsの軽さ×100+lbの出力は強み。**自重/バンド器具よりも高強度**を携帯サイズで実現する点は差別化。ただし**エキセントリック負荷非対応（コンセントリック中心）**は上級者ニーズに限界。([Facebook][6])
* **訴求力：中** … 「出張・旅先・省スペース×本格筋トレ」をわかりやすく訴求できる。動画クリエイティブ次第でMakuakeでも訴求可能だが、**価格・付属品・耐久性・ケーブル交換周期**等の不安は要解消。([MAXPRO Fitness][7])

**総括**：**評価＝「中」**（大：— / 中：◯ / 小：—）

# ⑨ 規制（PSE/技適）

* **PSE**：**本体が自力式でAC給電不要なら原則PSE対象外**。ただし**付属のACアダプタ（同梱する場合）**や**充電式BTモジュール/ドングル**を同梱するなら、**該当アダプタはPSE対象**（丸PSE/菱PSEの要否は区分次第）。**アダプタは供給元PSE済み品を採用**が実務的。費用はアダプタ側の調達で内包可能。([Makuake][14])
* **技適（Telec/MIC）**：**Bluetoothモジュールを搭載/同梱する場合は技適必須**。**モジュール既認証の流用**ができれば低コスト短納期、**新規試験は数千USD規模**。([Certification Japan][15])
* **製品仕様の揺れ**：Airは「**No power cords / No batteries / No app dependency**」の記述がある一方、**"アプリ連携/USB充電"**を示す文面も見られるため、**量産仕様の確定確認が必須**。**BT搭載なら技適、充電器同梱ならPSE**を前提に工程・費用を設計。([キックスターター][3])

# ⑮ 最終判定（事業者目線・厳しめ）

* **Makuake成功確度**：**「中」**
* **取り組むべきか**：**条件付きで「慎重検討」**

  * **Go条件**：①**技適・PSEの不要化**（BTレス/ACアダプタ非同梱）**または**既認証モジュール/アダプタの採用確約、②**FOB $250以下**（or 総原価¥4.0万円台前半）確保、③**税込64,800円前後**でも訴求可能な**動画/体験クリエイティブ**の用意、④**日本ECの既存MAXPROとの棲み分け**（Airの携帯特化を前面化）
  * **NG条件**：①BT/充電器同梱で**追加認証・コスト負担**が増大、②**FOB $280**超で利幅が**6万円台でも薄利**、③並行流通の整理不可
* **理由**：**ブランド認知はあるが（Amazon.co.jp既流通）独占/差別化が難しく、利益率は価格設定に敏感**。広告が当たれば黒字化は十分あり得るが、**条件が1つ崩れると一気に収益性が悪化**。
